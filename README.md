# vimtc-website

Rebuild of [www.vimtc.org](https://www.vimtc.org) (Victory International Ministry Training College) from a Proweaver-built WordPress site to Next.js on Vercel.

- **`main`** — the new site (Next.js 16, Tailwind v4, Resend). Not yet scaffolded; see the plan.
- **`export`** — raw export of the current WordPress site (theme, uploads, database dump). Reference only; never deployed. Contains credentials in the SQL dump, so this repo must stay private until that file is purged.

Start with [`docs/MIGRATION-PLAN.md`](docs/MIGRATION-PLAN.md).
